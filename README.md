# Vemparajugari Vantillu — Digital Menu

A mobile-first digital menu for Vemparajugari Vantillu.

## Product direction

One restaurant brand with two menu areas:

- Restaurant food — biryanis and other verified food offerings.
- Pickles — non-veg pickle products offered by the same restaurant.

The customer experience is intentionally simple, bilingual (Telugu + English), responsive, and visually inspired by the restaurant's heritage identity without copying the physical board design.

## Current design principles

- Preserve the supplied brand identity.
- No invented menu items, ingredients, prices, pack sizes, awards, or history.
- Clear pricing and serving-size presentation.
- Mobile-first navigation with large, easy-to-tap controls.
- Owner/admin controls will be added after the menu data is verified.

## Run locally

```bash
npm install
npm run dev
```
